# Security Policy

This repository contains research software, provided as-is, without a support or security-fix SLA.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public GitHub issue with exploit or vulnerability details.

1. Use [GitHub private vulnerability reporting](https://github.com/glsalierno/cas-to-HSPiP_data/security/advisories/new) for this repository, or
2. Contact the maintainer privately through the contact methods on their GitHub profile.

Include the affected version or commit, a minimal reproduction, and the impact. Allow reasonable time for a response before any public disclosure.
